Как я работаюHow I work

  • Начинаю с задачи пользователя и ограничений, а не с картинки: сценарий, роли, данные, краевые случаи.I start from the user's job and the constraints, not from a picture: the flow, the roles, the data, the edge cases.
  • Сначала собираю систему: переменные, стили, компоненты. Экраны потом собираются из экземпляров, а не рисуются заново.I build the system first: variables, styles, components. Screens are then assembled from instances, not redrawn.
  • Пользуюсь AI-инструментами: для сводки по конкурентам, генерации иллюстраций и видео. Каждое решение и каждый кадр проверяю и отбираю сам.I use AI tools for competitor summaries, illustration and video generation. I review and select every decision and every frame myself.

Инструменты: Figma (переменные, компоненты, прототипы), FigJam, Higgsfield AI, Notion, базовые HTML и CSS.Tools: Figma (variables, components, prototyping), FigJam, Higgsfield AI, Notion, basic HTML and CSS.
