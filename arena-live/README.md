# Арена Live

Виджет спортивных событий на реальных данных, собранный на дизайн-системе Арены.

- `index.html` — виджет: виды спорта, дни, фильтр по статусу, поиск, live-счёт, коэффициенты 1X2, купон.
- `system.html` — документация: токены, типографика, компоненты и правила.
- `tokens/` — выгрузка переменных из Figma (`figma-export.json`) и сборка (`node tokens/build.mjs`) в `css/tokens.css`, `tokens/design-tokens.json` (W3C DTCG) и `js/tokens.js`.
- Данные: публичный scoreboard API ESPN. При недоступности — `data/snapshot.json`.
- `?state=` в адресе включает режим проверки: `loading`, `slow`, `partial`, `error`, `moving`, `empty`, `long`, `nologo`.

## Что всплыло на реальных данных

1. **Стрелки движения линии стояли почти на каждой кнопке.** API отдаёт линию открытия, которой бывает несколько дней. Движение теперь считается от того, что пользователь уже видел в этой сессии, и гаснет через 15 секунд.
2. **Матч «сегодня» оказывался во «вчера».** ESPN режет дни по времени Нью-Йорка: игра НХЛ в 00:00 по Калининграду числится за предыдущую дату. Виджет запрашивает две соседние даты и раскладывает события по местному дню.
3. **Во время матча коэффициенты пропадают.** Приём ставок приостанавливается — появилось состояние «заблокировано», которое держит место в сетке, чтобы строки не прыгали.
4. **Коэффициенты приходят в американском формате** (+150 / −115) — переводятся в десятичные.
5. **Часть лиг может не ответить.** Вместо общей ошибки — баннер с названием упавших лиг, остальное показывается.
6. **В международную паузу пустые виды спорта.** Они не скрываются, а приглушаются, чтобы навигация не менялась от дня к дню.
7. **В светлой теме выбранный коэффициент при наведении становился белым на белом** — ховер перебивал выбранное состояние. Исправлено порядком правил.
8. **На 390 px «Завершены 8» не помещался** в сегментированный фильтр — фильтр стал прокручиваемым.
